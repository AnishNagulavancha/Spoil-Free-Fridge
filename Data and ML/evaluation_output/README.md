# Canonical evaluation artifacts

Only the current House A provenance chain is retained here:

- `full_stack_4runs_20260806/` contains the final aggregate reports, plot, and
  compact result summaries for three controls, one excluded pilot, and three
  confirmations.
- `house_a_v1_robustness/` contains the completed robustness report and compact
  audit summaries for v1.
- `house_a_v2_candidate/` contains the frozen v2 configuration, final report,
  development-only rule selection, and compact session summaries.

Staged features, fitted joblib files, detailed per-bin metrics, and sensitivity
tables are regenerated by the analysis scripts and are intentionally ignored.
Raw acquisition folders remain outside `evaluation_output` and must not be
treated as generated disposable files.
